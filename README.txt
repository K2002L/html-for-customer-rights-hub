Consumer Rights Platform - Improved Flask Prototype

## Live Demo

Deployed on Render:  
https://your-render-url.onrender.com

How to run:
1. Open this folder in PyCharm.
2. Create/select a virtual environment.
3. Run: pip install -r requirements.txt
4. Run: python app.py
5. Open: http://127.0.0.1:5000

This version includes:
- Login / register page
- Homepage with three main dispute categories
- Shopping, fraud, and subscription guidance pages
- 3-step complaint submission flow
- Case progress dashboard and case detail pages
- Rights knowledge page with alerts and FAQ
- Human support page
- Community success cases page
- Accessibility controls on every page
